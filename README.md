- Collects and analyzes system telemetry.
- Integrates a Python monitoring agent with a FastAPI backend.
- Provides a dashboard for system health monitoring.
- Explores predictive issue detection using Machine Learning.

**Tech Stack:** Python, FastAPI, React.js, Machine Learning, System Monitoring

### 🌍 2. Aegis – AI-Powered Climate & Disaster Risk Intelligence

A data-driven platform designed to analyze environmental conditions and identify potential climate and disaster risks.

- Integrates weather, rainfall, geographical, and historical disaster data.
- Performs exploratory data analysis and feature engineering.
- Explores forecasting and predictive risk modeling.
- Uses cloud data architecture and visualization workflows.

**Tech Stack:** Python, Machine Learning, AWS, Snowflake, Geospatial Analytics, Streamlit

- Developed insights to support customer retention strategies.
